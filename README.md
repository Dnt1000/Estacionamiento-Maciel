# Autocentro Maciel

Sitio web oficial de **Autocentro Maciel**, un establecimiento de estacionamiento, lavadero y detailing ubicado en Montevideo, Uruguay.

El proyecto busca ofrecer una experiencia digital sencilla e intuitiva, permitiendo a los clientes conocer los servicios, consultar tarifas y realizar consultas directamente desde la página.

🌐 **Sitio web:** https://autocentromaciel.com

---

## 📌 Características

- **Página de inicio:** presentación visual del establecimiento mediante un carrusel de imágenes.
- **Promociones:** sección con imágenes de las promociones disponibles.
- **Parking:** consulta de tarifas por hora, día y mes.
- **Lavadero:** catálogo de servicios de lavado con precios según el tipo de vehículo.
- **Detailing:** información sobre servicios especializados para el cuidado del vehículo.
- **Consultas interactivas:** selección de servicios y generación de consultas personalizadas mediante WhatsApp.
- **Galería de imágenes:** visualización ampliada de fotografías mediante Lightbox.
- **Ubicación:** integración con Google Maps para facilitar el acceso al establecimiento.
- **Contacto:** acceso directo a WhatsApp, teléfono, correo electrónico e Instagram.
- **Diseño responsive:** adaptación de la interfaz a dispositivos móviles y computadoras.

## 🛠️ Tecnologías utilizadas

| Tecnología | Uso |

## 🚀 Instalación y ejecución

1. Clonar el repositorio:

```bash
git clone URL_DEL_REPOSITORIO
```

2. Ingresar a la carpeta del proyecto:

```bash
cd Autocentro-Maciel
```

3. Abrir `index.html` en el navegador o utilizar una extensión como Live Server en Visual Studio Code.

No requiere instalación de dependencias ni configuración de un servidor backend para su funcionamiento actual.
